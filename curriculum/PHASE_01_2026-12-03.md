# Phase 01 Curriculum — 2026-11-03 → 2026-12-03

## Final exam

By **2026-12-03**, perform one coherent interactive album/live set without requiring a separate musician.

Minimum output:
- 4-act large-scale arc;
- 3–4 strong playable pieces or systems;
- at least one piano/electronic study;
- at least one process/mathematical study;
- at least one spatial/gesture-driven study;
- one human–Agent co-creation study;
- Ableton/Max/WebAudio implementation as appropriate;
- versioned performance project;
- 12–20 min showcase mode and a path toward a 25–45 min full mode;
- documented SAFE/fallback behavior;
- public-safe research notes.

This curriculum compresses principles found in current MIT, Princeton, Berklee and NYU music-technology / live-electronic courses: repeated creative assignments, instrument/interface building, listening and critique, interactive systems, live rig design, rehearsal, troubleshooting and a culminating project.

## Daily loop

Do not study all day without producing sound.

```text
READ / LISTEN       30–45 min
ANALYZE              20–30 min
BUILD                60–120 min
PLAY / RECORD         20–30 min
CRITIQUE              10 min
LOG                    5 min
```

Every work session should leave one artifact: WAV, MIDI, patch, JSON, diagram, timeline, score or written decision.

# WEEK 1 — LANGUAGE / EARS / BASIC SYSTEMS
**Nov 3–9**

Goal: learn to hear mechanisms instead of genre labels.

## Listening families

- KASHIWA Daisuke — `TITAN`, `program music I`, selected `program music II`.
- Daito Manabe — `dm studies 000–004` + public research systems.
- YMO — selected early and `BGM`-era work; listen for sequence/human relationship.
- CAPSULE — compare early technopop / later club-focused work; listen for production constraint and pop legibility.
- 2–3 current NIME embodied-interface works.

## Exercises

### E01 — One sound, six states
One original sound only. Create Idle / Seed / Build / Hold / Peak / Release.

### E02 — One-button composition
One button controls a musically meaningful transition. No continuous knob required.

### E03 — Fixed piano / variable electronics
Write a short original piano/MIDI phrase. Electronics may transform density, register, cut, spectral width or low-frequency weight without changing the phrase itself.

### E04 — Two clocks
Create a 4:3 or 5:4 relationship and learn to hear when they align again.

## Week 1 deliverable
Four 45–90 second studies. Keep only the two you want to hear again.

# WEEK 2 — SOUND / TIME / PERSONAL CORPUS
**Nov 10–16**

Goal: establish original sonic material and a repeatable sound-design workflow.

## Exercises

### E05 — FM percussion kit
Synthesize kick / transient / metallic / noise voices from scratch.

### E06 — Personal corpus
Record or generate 20–50 short original sounds. Analyze/sort them. Do not start with a giant downloaded sample library.

### E07 — Cut Memory
Slice one source into a composition while retaining recognizability of its material identity.

### E08 — Spatial Grain
One semantic variable simultaneously affects sound and visual/spatial state.

### E09 — TITAN mechanism reconstruction 01
Do not cover a track. Extract one observed structural mechanism and rebuild it using original notes/timbres.

## Week 2 deliverable
Six named presets / mechanisms, each with preview audio and a parameter JSON/notes file.

---

# WEEK 3 — PERFORMANCE / AGENT / SELECTION
**Nov 17–23**

Goal: turn composition mechanisms into instruments and reduce scope.

## Agent rule

Agent proposes/edit structures; performer retains final audition, approval and live control.

### E10 — Agent Arranger
Give an Agent a fixed set of stems/MIDI and constraints. Ask for three structural variants. Audition blind if possible.

### E11 — Agent Critic
Define explicit criteria before asking for critique. Compare its diagnosis with your own listening notes.

### E12 — State JSON
Represent one piece as inspectable `state / event / transition` data and drive at least two outputs from it.

### E13 — Embodied control
Map hand / foot / MIDI / OSC / optionally EMG research input to semantic controls rather than raw parameter sprawl.

## Selection gate

Reduce the 12-mechanism pool to **6**, then to **3–4 performance candidates**.

A candidate survives only if:
- you want to hear it again;
- it has a distinct mechanism;
- it works when the performer pauses;
- live control improves it;
- it can recover from input loss;
- it contributes a unique role to the album arc.

# WEEK 4 — ALBUM / SHOW / REHEARSAL
**Nov 24–Dec 2**

Goal: stop researching new branches and assemble one performance.

## Build

```text
ACT I   SEED / ORIENTATION
ACT II  EXPANSION / SYSTEM
```

## Rehearsals

Run at least:
- one no-visual rehearsal;
- one no-Agent/fallback rehearsal;
- one deliberate network/input-failure rehearsal;
- one full audiovisual capture;
- one showcase-length run;
- one longest practical run.

After Nov 29, avoid major architecture changes unless a blocker makes the show impossible.

# DEC 3 — PHASE 01 EXAM

Deliver:
1. complete live performance;
2. stereo reference recording;
3. screen/stage capture;
4. project snapshot / git tag;
5. track/state metadata;
6. short reflection: what became your musical language and what still feels borrowed?

## Pass condition

The result does not have to prove mastery of music production.

It must prove something more specific:

> You can construct, understand, rehearse and perform a musical system whose form can respond to input without losing musical identity.
