# Principle 02 — Album and Live-Set Architecture

There is no universal “correct” electronic-album structure. For Performable Music, use structural models as tools rather than rules.

## Four useful album models

### A. Narrative Arc

```text
Orientation → Expansion → Rupture/Peak → Release/Afterimage
```

Best when the album should feel like one journey.

### B. Suite / Continuous World

Several pieces behave like different rooms in one environment. Transitions, recurring motifs, shared sound materials and crossfades matter more than track boundaries.

### C. Contrast Grid

Alternate high/low energy, dense/sparse, acoustic/electronic, fixed/generative. Good when each track has a strong individual identity.

### D. Process Evolution

The same generative rule or material is transformed across the release. The listener gradually understands the system itself.

## Phase 01 choice

For the 2026-12-03 live album, start with **Narrative Arc + Process Evolution**.

### ACT I — SEED / ORIENTATION
Purpose: teach the audience the sound-world and the performance grammar.

Musical behavior:
- clear pulse or sparse event language;
- one identifiable motif/timbre;
- low parameter count;
- performer actions are easy to understand.

Candidate studies:
- ZERO STATE
- CITY MACHINE
- restrained piano/electronic study inspired by the KASHIWA research method

### ACT II — EXPANSION / SYSTEM
Purpose: expose the system and add interacting clocks/layers.

Candidate studies:
- POLYPHASE
- FM ALLOY
- CUT MEMORY

### ACT III — MUTATION / PEAK
Purpose: let interaction history, space, Agent decisions or spectral instability transform the established rules.

Candidate studies:
- SPATIAL GRAIN
- NEURAL MEMORY
- AGENT REMIX
- SPECTRAL TENSION

### ACT IV — RELEASE / AFTERIMAGE
Purpose: reduce complexity, reveal a memorable harmonic/melodic identity and leave a sense of resolution.

Candidate studies:
- ORBITAL DELAY
- LUMINOUS RELEASE
- selected piano/electronic reconstruction language from the KASHIWA research

## Local track state machine

Each piece can expose:

```text
Idle
  ↓
Seed
  ↓
Build
  ↓
Hold ↔ Variation
  ↓
Peak
  ↓
Release
```

A performer does not need to manually control every transition. Some may be clocked, some event-driven, some conditional.

## Album-level performance rule

The album must support at least two durations:

- **showcase mode** — 12–20 minutes;
- **full live mode** — 25–45 minutes.

This forces pieces to be extendable and interruptible rather than fixed to one render length.

## The key distinction

A conventional album asks: “what happens at minute 03:42?”

A performable album also asks:

> “what states are possible here, what can the performer change, and how does the system still know where it is going?”
