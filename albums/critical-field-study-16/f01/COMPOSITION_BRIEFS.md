# F01 — MICRO / DATA PRECISION

**Lineage / methods, NOT stylistic cloning:** Ryoji Ikeda: +/- (1996), matrix (2000), dataplex (2005), test pattern (2008). Learn perceptual scale and extreme precision, not his exact frequencies or imagery.

**Research mechanism:** A sparse quantized event lattice, stable micro-events, one rare disruptive event. The grid must make musical sense without white flashing.

**Signature instrument / free-tool route:** Bitfield Instrument: scheduled impulses + resonant filter bank + sub-pulse; quantization, probability and negative-space gates. A Surge XT metallic pluck is a sketch fallback; plugdata/SC can provide original event DSP.

## Two ORIGINAL full-length composition briefs

### F01-1 — Unit Cell (120 BPM, target 4 min)
**Role:** micro / quiet / cerebral

**Time-ordered form:** 0:00–0:38 establish three timbral classes; 0:38–1:22 one clock with holes; 1:22–2:10 exact sub events create body; 2:10–3:02 remove most events, preserve a 5-step motif; 3:02–4:00 accelerated return then near-silence.

**Distinct composition principle:** Event geometry is slow enough that each click has a function; dynamics from interval and silence, not loudness.

**Delay/reverb/mix design:** No full-bus reverb; only two bright hits to 0.15–0.4s early reflections; short tempo-free delay on isolated events.

**Performable controls:** precision → scheduling grid tightness; aperture → exposed voices; PINCH triggers rare structure reversal.

**Visual spatial coupling:** single grid cell → an ordered field; same event IDs trigger light points.

**Output contract:** original 24bit/48k stereo preview; dry/wet and tonal/percussion stems; MIDI/score.json; synth/FX parameter snapshots; Show Score/control mapping; tested saved/reopenable DAW project where the local app allows; A/B listening annotations. No audio quality PASS without human audition.

### F01-2 — Error Horizon (137 BPM, target 4 min)
**Role:** micro / brutal / discontinuous

**Time-ordered form:** 0:00–0:27 static precise click; 0:27–1:08 deliberate nonperiodic omissions; 1:08–1:53 micro-events accelerate while pitch register moves down; 1:53–2:38 hard silence + low-only events; 2:38–3:30 bounded overload; 3:30–4:00 break down to one original pulse.

**Distinct composition principle:** An intentionally broken syntax and negative space, NOT the previous track at a faster BPM.

**Delay/reverb/mix design:** Spectral narrowing versus widening is the primary effect. Keep headroom and harsh high-frequency safety; no sustained high-level tones.

**Performable controls:** fault → omission/insert rate; scale → micro-to-architectural grouping; FOOT toggles source/derived grid.

**Visual spatial coupling:** error codes fracture and reorganize spatial geometry; avoid imitation of artist-specific data visualizations.

**Output contract:** original 24bit/48k stereo preview; dry/wet and tonal/percussion stems; MIDI/score.json; synth/FX parameter snapshots; Show Score/control mapping; tested saved/reopenable DAW project where the local app allows; A/B listening annotations. No audio quality PASS without human audition.

## Studio acceptance
- Listen to both without visuals at matched playback loudness; they must sound like different compositions, not different effect presets.
- At least one identifiable musical event, one meaningful structural contrast and one intentional silence in each piece.
- Distortion, delay, reverb, stereo/space and sub-bass must be purposeful and bounded; document release/tail design.
- No artist recordings, copied melody, cloned sound signatures, unlicensed code, private WAV or unverified stage claims.
