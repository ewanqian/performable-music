# Albums

This directory holds original album-scale work.

Recommended structure:

```text
albums/<project-name>/
  README.md
  concept.md
  tracklist.csv
  tracks/
  midi/
  presets/
  renders/
  live-mappings/
  sources.md
```

## Rule

Do not begin by finishing 12 tracks in parallel.

For the current research cycle:

```text
12 mechanisms
  -> listening pass
  -> 6 short playable studies
  -> 3–4 strong live works
  -> expand the surviving language into an album
```

A track is considered a **performable track** when it still has a coherent musical identity with the performer doing nothing, but exposes a small set of meaningful controls that can reshape timing, density, timbre, space or form live.
