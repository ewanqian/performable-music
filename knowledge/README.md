# Project Knowledge

This directory stores durable, public-safe project memory.

## What belongs here

- architecture decisions;
- naming decisions;
- research questions;
- accepted/rejected hypotheses;
- tool/version choices;
- album/live-set direction decisions;
- reasons for selecting or dropping a prototype.

## What does not belong here

- private conversations;
- credentials;
- personal sensitive information;
- raw copyrighted reference materials;
- temporary brainstorming that has not survived review.

## Decision format

```text
DATE:
DECISION:
WHY:
EVIDENCE:
ALTERNATIVES REJECTED:
REVISIT WHEN:
```
