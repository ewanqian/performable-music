# Library

Reusable **original or properly licensed** musical material for performance systems.

This is not the core identity of the repository, but a useful output of research.

Suggested categories:

```text
library/
  ambient/
  opening/
  transition/
  climax/
  ending/
  textures/
  pulses/
  stems/
```

Every reusable object should progressively gain Performance Metadata:
- energy / density / tension;
- BPM/key where meaningful;
- loopable / extendable / interruptible / layerable;
- compatible inputs;
- state behavior;
- visual coupling;
- source / license / author.

Do not place third-party reference audio here unless the license explicitly permits redistribution.
