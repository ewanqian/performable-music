This work uses a continuously excited native FM/nonlinear instrument, with four
saved CV gesture curves. No new MIDI song, note sequence, bass loop, random
variation or added audio track. The recorded performance is programmed parameter
playing, not human real-time playing. Live macro mode is a separate operating
mode of the same instrument, not another composition.

Listen first to the full90s WAV. Then inspect the29–41s weakest-candidate excerpt
and the58–62s critical gesture. The weakness analysis is based on actual spectra
and parameter trajectories, not a model claiming to have heard the music.
