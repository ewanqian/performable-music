# Live Sets

This directory holds concert/performance systems derived from album and research material.

Recommended structure:

```text
live-sets/<date-or-project>/
  README.md
  show-score.json
  ableton/
  max/
  visual/
  input-mappings/
  runbook/
  rehearsal-notes/
```

## Performance principle

Separate composition from interaction:

```text
stable musical structure
      +
small meaningful live control surface
      +
independent SAFE / KILL
```

A live set should not depend on an agent making high-frequency decisions during performance. Agent output should preferably be committed beforehand as plans, MIDI, scenes, presets or bounded macro states.

Stage Casting 04 can be linked or imported here when its local performance system reaches a stable version.
