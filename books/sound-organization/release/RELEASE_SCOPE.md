# 六组版发布范围

本次按作者2026-11-17的明确要求：先完成并发布现有六组24章版本，再从发布提交创建两篇整合实验分支。

阅读正本以已批准的R7附件为基线，保留其前言、五篇正文、默认展开的旁注、200条历史索引和工具/叙事分层。远端旧稿及并行第20章保留在Git历史；第20章只整合对黑川作品有独立作用的内容，不重复第18章NONOTAK和路由讨论。

本目录保存六组发布版源稿和构建入口。正文不包含编务记录。所有新章必须有完整叙述、明确身份、来源脚注和前后承接。主书、示例材料、Live实机测试状态分开；不把数值测试称为听觉验收，不虚构艺术家私有工程。

仅为本书更新Pages打包路径，保留现有实验站点；发布前检查24章、来源、媒体、内部链接、可访问性与隐私。公开页只输出读本、历史知识库和自有教学材料，不输出内部审稿记录。

两篇结构不进入本次六组版；在发布完成后另建分支，不覆盖已发布路径。
