## 网页审读

在本目录运行 `python build.py`，生成可离线阅读的 `site/index.html`。正文、脚注和完整目录在同一个文件内；作品录像只有在点击后才连接外部平台。默认不自动播放、不加载第三方追踪脚本。网页不依赖 Node、外部字体或在线 Markdown 服务。

仓库中的 Markdown 是正文正本。生成页面不单独编辑。作品链接属于对应艺术家、机构或发行方；不会把其录音下载、镜像到仓库。
