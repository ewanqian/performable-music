# Research Journal

Use one dated Markdown file per meaningful research session.

Suggested path:

```text
journal/YYYY/YYYY-MM-DD-short-title.md
```

Template:

```markdown
# YYYY-MM-DD — Title

## Question
What was I trying to understand or make?

## Inputs
Sources, tracks, patches, datasets, devices.

## Experiment
What I actually did.

## Result
What changed or became clearer.

## Evidence
Files, renders, screenshots, plots, commit hashes.

## Interpretation
What I think it means. Mark uncertain claims as INFERENCE.

## Decision
Keep / change / reject / repeat.

## Next single task
One concrete follow-up.
```

Keep journal entries public-safe. Private emotional/personal notes should stay outside this repository unless deliberately rewritten into research-relevant, non-identifying reflection.
