# Instruments

Reusable performance instruments and bridges.

```text
instruments/
  ableton/
  max/
  webaudio/
  midi-osc/
  analysis/
```

## Ableton
Arrangement, clips, stable instruments/effects, stems, show structure and versioned Sets.

## Max / Max for Live
Real-time DSP, gesture interpretation, state machines, custom instruments, OSC, smoothing, safety and audiovisual data sharing.

## WebAudio
Fast public prototypes and audition tools; useful for learning and sharing mechanisms before moving survivors into stage systems.

## MIDI / OSC
Protocols and mappings should remain inspectable, versioned and replaceable.

## Rule

An instrument is successful when it helps create or perform music, not when it exposes the maximum number of technical parameters.
