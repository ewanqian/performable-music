## Reuse decisions

**Shared adapters only**:
1. Canonical WebXR 25 joints/hand; tracking validity, loss, device timestamp and calibration.
2. Pinch, phalanx distance and dwell, two-hand vector, swept geometric hit regions, future grab/carry/drop.
3. Semantic source-tagged events (SIMULATED vs REAL_XR), stable IDs and normalized 0..1 controls; bridge to EXISTING protocols/show-score-v1.schema.json.
4. Existing authenticated WSS→OSC, with allowlists/stale handling, independent physical audio kill onstage.
5. Audio-engine abstraction (local Web Audio fallback; optional Tone or artist stems; desktop DAW via OSC).
6. Rendering target adapter: independent WebGL/Three viewports and correct camera mappings, single canonical asset manifest and QA contract.
7. Test harness: 10–25k synthetic gesture frames, actual 20x trials on Quest, sound A/B, browser JS frame estimates distinguished from compositor latency.

**Never pretend shared**: PolyNodes resynthesis DSP, ENTROPY spacecraft/reactor meshes, symbolic films/ritual graphics, environmental stage light patch, master camera choices, copyrighted source audio. An adapter can be shared; source content and artistic choices cannot be homogenized. Do not copy private models into a public GitHub repo without author rights review.
