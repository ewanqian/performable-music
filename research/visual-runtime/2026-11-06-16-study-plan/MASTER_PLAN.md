# Stage Casting × Performable Music — Visual Studies

**Public research overview · 2026-11-20**

This is a set of **16 candidate experiments** in author-led audiovisual creation and performance. It is a research map, **not** evidence that 16 demos or an entire live set have been produced.

## Research method

- Author chooses original or cleared media, visual language, framing, musical events and meaningful omissions.
- Existing visual runtime and Show Score events are reused rather than creating a separate engine for every experiment.
- First verify actual sound and a repeatable audio/visual event; only then broaden to 2D/3D materials, gestures and more advanced spatial inputs.
- Evaluate with working files, real tests, short playable previews and artist review. Mark untested items explicitly.

## Study families

1. Authored media and composition: original image/video plates, typography, curve/trajectory systems.
2. Performable control: shared audio/visual event identity, foot/hand control, state restoration and event replay.
3. Spatial source experiments: Blender geometry, point clouds, performance-driven movement and explicit camera cues.
4. Sound and stage research: meaningful sound-space relationships, timing and distinct operator/audience display roles.

See [EXPERIMENTS_16.json](EXPERIMENTS_16.json) for the individual proposed study IDs and evaluation criteria, and [Visual Runtime Lab](../../../visual-runtime-lab/) for executable research.
