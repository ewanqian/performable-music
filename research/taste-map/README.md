This is not a ranking of artists and not an attempt to “digitally clone” people.

- works worth revisiting;
- what specifically attracts us;
- documented methods / tools;
- analytical hypotheses;
- exercises derived from the method;
- collaboration context only when appropriate to publish;
- citations and acknowledgement needs.

## Personal taste is a dataset, not a mood board

Over time, each reference should produce structured notes such as:

```yaml
AttractedTo:
  - timing
  - clean synthesis
  - long-form release
  - physical bass
Avoid:
  - generic cyberpunk texture
  - complexity without musical consequence
MechanismsToTest:
  - two-clock rhythm
  - piano-fixed/electronics-variable
  - event-history memory
  - EMG effort -> tension
```

The purpose is to gradually discover recurring preferences that can be turned into an original compositional grammar.
