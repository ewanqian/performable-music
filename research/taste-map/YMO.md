# Taste Map — Yellow Magic Orchestra (YMO)

**Status:** public-safe working research card.

## FACT / SOURCE

Start with:
- https://daily.redbullmusicacademy.com/2014/11/yellow-magic-orchestra-gear/

Useful historical topics to verify from additional primary/archival sources before formal publication:
- use of Roland MC-8 / pre-MIDI sequencing;
- click-track synchronization between machines and human performers;
- live technical failure/overheating as a real performance problem;
- sequenced electronics coexisting with human timing and ensemble playing.

## INFERENCE — why this matters to Performable Music

The important lesson is not retro synth timbre.

It is:

> Electronic performance becomes interesting when machines introduce strict structure but humans retain responsibility for continuity, recovery and musical character.

This is a direct ancestor of the current Stage Casting problem:

```text
machine timing / sequence
+
human performer
+
explicit sync
+
failure recovery
```

## MECHANISMS TO EXTRACT

### Y01 — Machine Grid / Human Layer
One rigid sequenced layer + one freely performed layer.

### Y02 — Failure Is Part of Design
The piece should continue if one sequence/device disappears.

### Y03 — Constraint Creates Identity
Use a limited set of voices/patterns and make arrangement/performance create the variation.

### Y04 — Synchronization as Composition
Clock, cue, entry and stop behavior are part of the musical structure, not just technical setup.

## PRACTICE TASK

Create a 60-second study with:
- one machine-locked 16-step sequence;
- one manually performed or manually triggered layer;
- one deliberate sequence mute/failure at 30 seconds;
- a musical recovery that does not require restarting the whole piece.

## DO NOT COPY

Do not imitate a specific YMO melody, sound preset or arrangement. Rebuild the **human/machine relationship** with original material.

## ACKNOWLEDGEMENT MODEL

> Historical research influence: early live electronic performance practices associated with Yellow Magic Orchestra, particularly pre-MIDI sequencing, synchronization and the relationship between machine timing and human ensemble performance.

## OPEN QUESTIONS

- What should continue when the machine fails?
- Does strict timing make the human part feel more expressive or less?
- Which parts of a modern Agent/Ableton performance should be deliberately independent of the main computer sequence?
