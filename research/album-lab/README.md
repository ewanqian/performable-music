# Performable Album Lab — 12 Mechanisms

This is the current pre-album research pool. These are not twelve finished songs and not twelve genre exercises. Each item is a **playable composition mechanism** that can later become a track.

## Current 12

1. **ZERO STATE** — silence / pulse / decay; minimal event structure.
2. **POLYPHASE** — two clocks, rational ratios, drift and re-alignment.
3. **FM ALLOY** — original FM/noise percussion and metallic transient language.
4. **CUT MEMORY** — slice/resequence a bounded self-recorded or licensed source corpus.
5. **ACID FUNCTION** — pitch/gate/filter generated as functions; hands change function parameters rather than individual notes.
6. **SPATIAL GRAIN** — position simultaneously shapes grain/timbre, stereo/depth and visual space.
7. **SPECTRAL TENSION** — spectral width, detuning, noise excitation and large-scale harmonic tension.
8. **CITY MACHINE** — clean machine rhythm + bright extended harmony; a more accessible melodic anchor.
9. **NEURAL MEMORY** — repeated interaction changes later system response; deterministic saved state required.
10. **AGENT REMIX** — agents propose structured arrangement/effect plans, human retains approval and live control.
11. **ORBITAL DELAY** — spatial orbit becomes pan/delay/feedback path.
12. **LUMINOUS RELEASE** — fast pulse, restrained arpeggiation and a bright final-release language.

## Selection process

```text
12 rough mechanisms
    ↓ listen first
6 worth hearing again
    ↓ build 60–90 s playable versions
3–4 performance pieces
    ↓ deepen arrangement / sound design
album language
```

### Gate 1 — ears

Rate 1–5:
- want to hear again;
- musical identity;
- physical/emotional response.

### Gate 2 — performance

Rate:
- live playability;
- audiovisual same-source potential;
- technical risk;
- recovery / safe state;
- whether it remains musical with the performer temporarily still.

## Research influences, not templates

- KASHIWA Daisuke: piano/electronics, long-form dynamics, narrative/emergent form.
- Daito Manabe: mathematical/process composition, club physicality, audiovisual/system thinking.
- FluCoMa / corpus-based practices: personal sound corpus and descriptor-space instruments.
- Ableton / Max / WebAudio: implementation environments, not aesthetic identities.

Every surviving track must eventually explain its identity without needing to say “it sounds like artist X”.
