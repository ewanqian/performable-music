# Performable Music

A long-term research and creation repository for **music that can be performed as a system**.

This repository connects composition, live performance, audiovisual systems, spatial input, Ableton Live, Max/MSP/Jitter, Web Audio, and agent-assisted music research.

## Current research lines

1. **KASHIWA Daisuke / TITAN** — piano × electronics × bass × emergent form; track-by-track analysis and practice-based reconstruction.
2. **Daito Manabe lineage** — mathematical music generation, club-music physicality, audiovisual systems, spatial/biological input, and agentic composition.
3. **Performable Album Lab** — 12 playable composition mechanisms → 6 prototypes → 3–4 performance pieces → longer-term album works.
4. **Agent Music Systems** — Codex / Ableton / Max / Web Audio workflows where agents propose structured musical plans while human performance remains the final control layer.

## Core principle

> Do not copy a style. Extract a mechanism, document it, rebuild it with original material, then make it performable.

The main unit of research is not a genre but a **playable composition mechanism**: a temporal idea, timbral idea, live-control idea, audiovisual mapping, and safe fallback.

## Public-research rule

This is a **public** repository. Do not commit copyrighted reference audio, private correspondence, personal identifiers, private project files, credentials, or other sensitive context. Keep facts, analytical inference, and personal experiments clearly separated.

See `PUBLIC_RESEARCH_POLICY.md` before publishing research notes.
