# 第一轮 Demo 代办：宽时间、钢琴与低频

2026-11-18 · 归属 [The Point 双机制作](README.md) / [主任务 #57](https://github.com/ewanqian/performable-music/issues/57)。先读本轮 [音乐创作方向](MUSICAL_DIRECTION.md)。
本文件是制作目标，不是音频、视觉或现场已经通过的声明。

## 本轮最高优先级

**让值得长时间聆听的材料成为《复苏》的可表演版本，再让同一个视觉场景跟随它演奏。钢琴加电子为明确要验证的方向，低频与氛围承担重量。**

四个音乐候选（含复苏）和两项深化只作为首轮工作上限，不是交付配额或专辑曲目数；当前一次只精修一项。已有作品与R0可直接复用，没有必须新增曲风的要求。三个视觉实验仍为候选，先增量完善已有V1，按音乐的实际需要推进V2/V3。

撤销旧版“45–60秒内交代开始、发展、结尾”和“每段60–90秒、凑约三分钟”的强制结构。短片可检查某个声音，宽时间判断必须保留足够的停留；采用自然片段，不为交付数字压缩或复制音乐。首次连续证明建议约4–6分钟，实际时长如实记录，仍不代表完整节目。

## 1. 音乐候选：保留ID，改变评审重点

| ID | 作曲目标 | 首份可判断输出 | 不通过的典型情况 |
| --- | --- | --- | --- |
| M0 · 复苏基线 | 选出有身份的既有材料，重新判断停留和转折 | 实际源版本、自然片段与保留理由；可交完整旧版并标区间 | 因已有成品就自动入选；未试听就整体重写 |
| M1 · 触击 | 稀疏低音、重击与粗颗粒的重量，事件之间留出压力 | 建议120–180秒自然段；可由已选R0增量发展 | 必须变鼓点、靠更响取胜、堆层掩盖单个声音薄弱 |
| M2 · 漂移 | 声场、远近和材质组织时间；可从独奏余音派生 | 源声到一项材质变化的自然片段，建议90–180秒，无需压缩成完整小曲 | 同循环加混响、无选择的随机、刺耳轰鸣掩盖无发展 |
| M3 · 回返 | 钢琴优先的独奏加电子，演奏的触键/声部/呼吸先成立 | 建议90–150秒裸钢琴与电子对照；可复用M0中合适材料 | 玩具感、机械力度、电子遮掩弱演奏、强制抒情解决或无关炫技 |

这些时长是听觉观察建议，不是统一模板。允许只交一段成立的中部。M3可研究小提琴作为有条件的独奏声源，但它不能占第五席，也不能取消钢琴验证。

R0被选入就占M1/M2对应席位；不增加相同材料的新任务。候选的状态与保留理由由真实试听决定。

- [ ] 每个文件对应真实工程、源版本、声源和作者；MIDI编程、实录演奏与音频推测分别标记。
- [ ] 比较副本的播放响度接近，同时保留段内动态；无视觉辅助也愿意继续听。
- [ ] 每项说明其音乐差异，附至少一个实际时间码；不能仅给曲风标签。
- [ ] 艺术家给KEEP / REVISE / REJECT。先把一项修到值得继续，首轮最多选择两项深化，一次只精修一项；已有材料可入选，不要求新增方向，不为凑数通过。
- [ ] 钢琴尚未通过时明确记录缺口，不能让四候选形式上的完成掩盖本轮明确要求。

## 2. 演奏控制：先两个，最终最多三个

| 操作 | 演奏含义 | 验证内容 |
| --- | --- | --- |
| 展开：连续量 | 改变材质或承重关系；各段只选一个清楚维度 | 音量接近时仍听得出改变；不直接推master |
| 介入 / 释放：按住与松开 | 在可延长节点停留，或引入有界回应，再退出 | 钢琴句内部保留呼吸；余音/电子可延长，释放后继续成立 |
| NEXT：入选后增加 | 按已设计边界放行下一句或下一段 | 自由时间用人工cue，节奏段用真实乐句边界，不把所有音乐拉齐小节 |

首个证明用既有键盘/MIDI；XR沿用同一语义，音乐不等待新输入硬件。详细独奏处理、Warp/循环边界与同材料两次演奏标准见 [音乐方向](MUSICAL_DIRECTION.md#5-可表演性的具体结构)。

- [ ] 同段做三次介入—变化—释放，录下实际声音和输入，未出现卡住持续音。
- [ ] 两次演奏同材料，一次更久停留，一次提前释放；时间组织确实不同，两次都能自然结束。
- [ ] 实际工程可保存重开，能中段停止、回到起点；既有停止机制继续可用。
- [ ] 同一事件先有可听后果，再交给视觉；不把按钮亮起等同于音乐控制成功。
- [ ] 实测BPM、真实MIDI、人工cue与音频派生值分别记录，沿用 [交接契约](HANDOFF_CONTRACT.md)。

## 3. 视觉清单：三个短实验，共用现有资产

| ID / 优先级 | 具体做什么 | 基础完成标准 | 已有基础与范围 |
| --- | --- | --- | --- |
| V1 · 石体显影 / 必做 | 选现有Boulder与Reactor恢复效果的最佳灯态；做顶/底或左右一次清晰转换，再做一次扫描显露 | 15–30秒；静帧材质与空间成立；绑定至少一个正式音乐事件；标明消费音乐版本 | 已报告15秒离线片与三灯态，先审阅再增量改，不从零重建 |
| V2 · 空间HUD / 第二顺位 | 在同一场景加一组空间标记，完成出现—锁定/跟随—收束三个动作；只读真实cue/对象状态 | 15–20秒；三个状态各有可读变化；共用一个实际事件入口；不遮住主体 | 使用现有机位/资产；最多一组标记，不扩成完整科幻桌面或控制平台 |
| V3 · 身体留痕 / 探索项 | 用已报告的排练动作关节代理，选一个伸手/侧移动作，表现石层迟滞与一处残留 | 15–20秒；关闭闪烁后仍看懂动作和后果；准确标为代理/缓存或实际输入 | 有现成动作代理，但未证明成片质量；不新搭全身动捕或高精数字人。若短实验仍看不懂，后排，不阻塞音乐 |

三个是候选试验，不要求三个都进入演出。先保住V1，V2可以成为同一视觉中的独立层；V3只进行一轮、最多45分钟的动作映射实验，到时交当前结果或明确后排，不影响工作段C。最终基础交付只要求一个被选中的主视觉系统。


## 4. 顺序与最低交付

### 工作段A：得到足够判断的材料

- [ ] 收齐M0/R0/V1，记录版本、已有成果与待审阅项。
- [ ] Mac优先完成M3钢琴裸声/电子对照，保留完整乐句与尾部。
- [ ] 对M0或M1做重量与停留验证；M0已经满足时不重做同类。
- [ ] Windows按已有V1反馈增量修改，正式音乐包到达前明确标临时配乐。

### 工作段B：按试听选择，最多深化两项

- [ ] 最多四个席位参与比较，不要求每个都重做新音频；M2按实际声场缺口补做。
- [ ] 一次精修一个对象，首轮最多深化两项；按实际声音覆盖独奏/情感与低频/空间，不足就保留待修，不强行通过。
- [ ] 小提琴没有合格演奏来源就后排；不影响钢琴和主体材料。
- [ ] Windows先保住V1；音乐确实需要时再推进V2，V3仍只用已有动作代理做一次有限试验。

### 工作段C：实际演奏

- [ ] 先用入选材料证明可停留、可改变和可退出；确有两段时再验证转场。各段时长依据音乐，转场不统一套15秒模板。
- [ ] 同一主视觉消费实际入选的正式音乐包，记录真实输入的音画后果；单段通过不冒称完整节目。
- [ ] 连续录制建议约4–6分钟；记录精确实际时长、包版本和控制日志。
- [ ] 第二次改变停留/释放，证明同材料存在可听的现场选择。
- [ ] 艺术家分别判断声音、画面与操作。

### 基础完成

- [ ] 至少一个连续音乐段经试听被选中且真正可控；钢琴要求有明确结果。候选数量不作为通过条件，完整节目另行排练验收。
- [ ] 一个主视觉已选中，与实际音乐包对齐。
- [ ] 同材料两次演奏、源工程可重开；多段材料入选时再验证一次自然转场。
- [ ] 短证明、后续长段排练与完整节目分别记录，不互相冒充。

通过后再扩展连续排练单元与完整节目，按 [音乐方向中的28分钟工作预算](MUSICAL_DIRECTION.md#7-现场与专辑同一组材料两种组织)排练；提案时段最终仍待主办确认。

## 5. 制作边界与状态

正式FUSU主工程由Mac当前唯一DAW owner处理；Windows Renew的已有独立音乐研究由原执行者保留和整理，选中材料交冻结包供Mac整合，不改Mac活动源。Windows同时继续既有资产/视觉工作，视觉工程留Atmospheric Escape。私人路径、参考录音、许可素材和团队媒体不进入公开Git。现有回报与未提交工作保留。

新引擎、控制台、批量生成、插件采购、第二套动捕和无关场景继续后排。钢琴质量、低频重量和自然时间组织优先于新增工具。

本清单没有启动本机进程或联系演奏者。M0已有作品；R0/V1有本地回报但本轮艺术审阅待补；修订后的M1–M3、控制与全场仍待真实验证。使用 [回执模板](RECEIPT.template.json)，主摘要归#57，私有视觉证据归Atmospheric Escape #13。
