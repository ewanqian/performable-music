# Study 004 — Two Clocks

## Goal

Learn to hear and perform **time relationships**, not just program complex rhythm.

Create two independent pulse systems using one ratio:

- 4:3, or
- 5:4.

Do not begin with 7:4 until the simpler relation is physically clear.

## Build

Clock A is the reference.
Clock B completes its own cycle over the same larger span.

Use clearly different timbres so the two clocks are easy to hear.

## Performance controls

Maximum three:

```text
BLEND    Clock A ↔ Clock B
DENSITY  events inside the clocks
RESET    force re-alignment
```

Optional later:
`RATIO` changes between 4:3 and 5:4.

## Exercise

1. Listen to A alone.
2. Listen to B alone.
3. Hear both together.
4. Mark where they re-align.
5. Mute one clock and bring it back without losing orientation.
6. Trigger RESET intentionally and hear the structural effect.

## Pass condition

PASS if:
- you can identify which clock is which without looking;
- you can predict or physically feel the next re-alignment;
- changing Blend/Density creates musical form, not only rhythmic confusion;
- RESET can function as a compositional event;
- the system still works with a very small sound palette.
