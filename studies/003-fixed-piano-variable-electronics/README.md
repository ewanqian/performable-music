# Study 003 — Fixed Piano / Variable Electronics

## Goal

Study the relationship between a stable melodic identity and a changing electronic environment.

Write one **original** piano/MIDI phrase of 4–8 notes. Do not change the notes after the first 20 minutes.

## Variables electronics may change

- density;
- octave/register doubling;
- spectral width;
- low-frequency support;
- interruption/silence;
- space/reverb/delay;
- granulation/chopping;
- distortion/noise field.

## Required form

Use the same phrase in at least three contexts:

```text
A — exposed / legible
B — transformed / pressured
C — returned / recontextualised
```

## Performance layer

Keep piano fixed. Expose only 2–3 electronic controls, for example:

```text
TENSION
DENSITY
SPACE
```

The live performer changes the environment, not the motif itself.

## Pass condition

PASS if:
- the motif remains identifiable through all three contexts;
- B feels meaningfully different without requiring a new melody;
- C feels like a return with changed meaning;
- live control can alter duration/intensity without destroying the form.

## Research connection

This exercise is motivated by questions raised in the KASHIWA Daisuke research line, but must use original notes, harmony and sound design.
