# Studies

Numbered studies are the exercises of the Performable Music curriculum.

Recommended naming:

```text
studies/001-one-button-music/
studies/002-two-clocks/
studies/003-piano-electronics/
studies/004-fm-percussion/
studies/005-cut-memory/
studies/006-spatial-grain/
...
```

Each study should be small enough to finish and audition.

Minimum files:

```text
README.md        question / mechanism / result
params.json      repeatable parameter state where applicable
midi/            original MIDI if used
patch/           Max/WebAudio/etc source
preview/         short original render or link to LFS asset
notes.md         what worked / failed / next test
```

A study is not automatically an album track. Most studies should be rejected or absorbed into stronger work.
