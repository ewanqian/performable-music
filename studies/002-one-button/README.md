# Study 002 — One Button Composition

## Goal

Use **one discrete event** to create meaningful musical form.

The button must not behave like a toy trigger. It should alter the piece at a structural level.

## Allowed button meanings

Choose one:
- advance state;
- capture/freeze;
- release/resolve;
- rotate to next variation;
- arm/disarm a process;
- restart/re-align two clocks.

## Constraint

No continuous controller is required for the first version.

Build a 45–90 second study where the performer can shape form using only:

```text
BUTTON
+
RESET / KILL
```

## Test

Record three performances with the same materials but different button timing.

PASS if all three remain recognisably the same piece while having genuinely different forms.

## Reflection

- Did the button change structure or merely trigger decoration?
- What musical information had to be fixed in advance?
- How long can the performer wait before the next press?
- What is the safe behaviour after a missed or double trigger?
