# STAGE CASTING 04 / SPATIAL WAVES + NEURAL FIELD

Created 2026-11-08. Priority: December 3 brain-signal audiovisual show. This is source development, not an accepted live performance.

## Creative reference

touch:waves by sascacci + ksmt is a 27-area audio+visual instrument where touch-and-drag changes sonic and visual feedback. Official NTT ICC archive: https://www.ntticc.or.jp/ja/archive/works/touch-waves/ . Interview: https://www.jfmusicwritterclass.com/entry/R-MONO_Lab . The application upgrades the *gesture and feedback mechanism* into a 3D field; it does not copy the composers' sounds, application code or graphics.

## New work

- spatial-waves.html: four distinct true-XYZ sphere volumes at two Z depths (PULSE/MINERAL/AIR/HARMONIC), 3 orthogonal rings per volume, 3D bridges, index-tip world-space contact, 60ms dwell, safe release and tracked loss; same source positions in desktop and WebXR rendering.
- spatial-waves-audio.mjs: four independently positioned Web Audio HRTF PannerNodes, original synthesis and AudioContext-clock-scheduled 16th rhythmic patterns at 100BPM. Includes four user-owned equal-duration stems imported locally: PULSE/MINERAL/AIR/HARMONIC, sharing one AudioContext playback start. No uploading. Stems required for professional sound quality; built-in oscillators are placeholders.
- Gesture map: enter increases that layer's presence and triggers sonic accent, move changes energy/filter, pinch brings intensity, bimanual spread separates sound-source positions. OSC via existing authenticated WSS performance bridge is optional.
- neural.html: schematic 3D brain surface and four stages STRUCTURE/SECTION/ELECTRODES/SIGNAL, original simulated 4 frequency-band preset envelopes. These are not live EEG or anatomically-registered imaging data. A separate existing neuro-field.html (procedural node-network sculpture) is retained unchanged.
- Both pages reuse the original LAB02 WebXR joint input adapter, do not reimplement hand tracking or falsify Quest metrics.

## IMPORTANT CONSTRAINTS

Scalp EEG captures population-level field potentials, not single-cell action potentials. Never claim a generated network visual depicts measured neuronal spikes. Label synthetic, recorded and live data separately; real EEG ingest needs source, montage, reference, sampling frequency, artifact flags and calibration.

HRTF PannerNode creates positional audio for a FIXED origin/listener in these pages. The headset listener orientation and translation are NOT currently bound to real XRViewerPose, so do not market it as verified head-tracked 6DoF/ambisonic spatial audio.

Google Three-Live v1.3.2 was published 2026-11-08 as Beta; it is a Google-hosted experimental/not officially supported project, recommended for an independently pinned static GLB/USDZ viewer/exports test, not to replace the stable Lab02 25-joint + OSC system. https://github.com/google/three-live/releases/tag/v1.3.2

An original downloadable GLB pack was created separately in the ChatGPT working container with 3 artistic stage models + one optimized brain-schematic variant. It is not committed to this GitHub repo nor installed directly on the user's Windows system; users must download/unpack it.

Anatomy model option: 49 BodyParts3D real anatomical GLBs in https://github.com/toby-bridges/brain-architecture-studio . The meshes remain CC BY-SA 2.1 Japan © DBCLS even though the code is MIT. Understand attribution and share-alike requirements before bundling into proprietary productions.

## SIX ACCEPTANCE GATES

1. Browser: source CI, Chromium desktop/mobile page errors, clickable four volumes, real audio startup/panic, Neural four modes, actual screenshots.
2. Local artist: listen to 4 source positions through actual headphones and import own 4 synchronized WAV stems; record 60s of original performance and decide if it feels like an instrument.
3. Quest: 20 real index-tip volume crossings per zone, 20 loss/occlusion cases, bimanual separation, 15min stress; record actual compositor FPS, not JavaScript rAF only.
4. Real Max/MSP→Ableton link: one authenticated WSS→OSC event must be heard and reproduced with quantized Show Score; keep independent physical mute.
5. Scientific/provenance audit: anatomical/source labels and licenses. No MRI/EEG claims for generated models.
6. Human director: approve one authored camera, one sound world, one 3–5m full live structure before adding more demo modes.

## 60s EDITORIAL FIRST TAKE

00–12s ACQUIRE: both hands appear, quiet drone and structural brain silhouette.
12–26s INSPECT: index pointing selects a volume/region and reveals a diagnostic line layer.
26–42s CONNECT: stretch two hands, increase source spread, harmonic route crossing.
42–54s PEAK: maintain a held sound volume while authored four-stem score adds rhythmic motion; no uncontrolled flash.
54–60s RELEASE: deliberate open gesture neutralizes the OSC gate and releases visual ring tension.

One writer per DAW session. Source CI is not evidence of verified Quest, AVP, EEG or finished music.
