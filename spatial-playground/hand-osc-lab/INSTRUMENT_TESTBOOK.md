## Architecture: the sensor is not the synthesizer

WebXR HANDS (up to 25 joints per side, pose/validity) → derived features (metric distances, 14 geometric bend angles, hand separation) → gesture state machine (enter / exit / release / hold, hysteresis, dwell) → **one continuously controlled instrument** (Web Audio filter, resonance, delay, feedback, slow oscillator motion, transient field) → low-cost single-GL visual overlay.

Optional live path: gesture params + semantic events → authenticated WSS → Node bridge → OSC UDP localhost → Max/MSP, Ableton, SuperCollider. Browser never opens UDP. Audio can work without OSC. Never route full-band master volume directly from raw unbounded positions.

## Gesture vocabulary implemented in V2

| Gesture | Musical meaning | Continuous/discrete |
|---|---|---|
| RIGHT thumb tip ↔ index tip pinch (28 mm on, 43 mm off) | Drone GATE envelope; hold to sustain | held state |
| LEFT thumb ↔ index distance | Lowpass cutoff ~130–6000 Hz | continuous |
| RIGHT thumb ↔ middle tip distance | Filter resonance | continuous |
| RIGHT thumb ↔ ring tip distance | Delay wet balance | continuous |
| RIGHT thumb ↔ pinky tip distance | Feedback/LFO modulation | continuous |
| Both thumb/index pinches sustained >=260ms | Toggle latch / HOLD | discrete, re-arm after both release |
| Index tip approaches middle PIP joint | Timbre preset cycle | discrete; test false positives |
| Left and right index fingertip separation | Stereo field placement | continuous |
| Hand vertical location | Energy parameter | continuous; do not directly expose full-gain |
| Index tip ENTER / EXIT A,B,C | Tuned impulse, may use 1/16 quantization at 100 BPM | event |
| Loss of tracking | Neutral / release; **never fabricate EXIT** | safety |

A/B/C transients differ in pitch and spectral filtering but this is a **synthesizer**, not a 12-key virtual piano. All tones are generated by Web Audio, with no music samples or copyrighted playback.

**Not yet implemented:** pinching an explicitly rendered *movable virtual token*, carrying it to a region, and dropping it there. The current 3D zones react to fingertip crossing, and pinch reacts as a sustain gate. That object-transport experiment is the next isolated task; do not claim it works now. Also not implemented: calibrated finger-to-joint anatomical contacts, object collisions with real-world geometry, fixed spatial anchors, physical haptics, multi-user sync.

## Tests to record on real Quest 3

Use same stage width, boundary, volume and lighting; capture headset model/version, browser version, time, audio route and OSC path. Evaluate first with OBS/Quest capture, then Max OSC logger. Write measured values, not guesses.

1. **T01 / Baseline regression**. Open Lab02 and Lab03 sequentially. Two hands, 25 joints each, stable joint lines, zone entered and exited exactly as expected. The two published URLs must stay independent.
2. **T02 / Gate and envelope**. Right thumb/index pinch 10 repetitions of slow/fast movement. Listen for no clicks or stuck voice, an audible timbre change during the finite phrase, and silence after release. Count dropped or false triggers.
3. **T03 / Independent finger timbre**. Sweep right thumb/middle, ring and pinky independently 10 times. Verify resonance, delay and modulation do not accidentally switch other controls. Compare spectrogram/audible behavior.
4. **T04 / Bimanual HOLD**. Both index pinches held for >260ms, release and repeat. Confirm exactly one toggle per press/release cycle. Hand tracking loss must clear latch.
5. **T05 / Cross-phalanx touch**. Bring index tip near middle PIP. Check at least 20 trials; record incorrect repeats and natural-pose false positives. Improve cooldown/rearm if needed.
6. **T06 / Spatial entry performance**. Enter and exit each of A, B, C at least 20 times. Compare free-trigger mode versus quantized mode at 100 BPM. Audio attack must be audible and cue-specific, not a keyboard scale.
7. **T07 / Capture-carry-drop — PENDING FEATURE**. Next implementation: pinch a visible virtual token, carry it through a field, release inside C; verify GRAB / MOVE / DROP semantic sequence, missed drop and neutral on tracking loss. Must add object hit/attach visual and tests before this can pass.
8. **T08 / OSC transport**. Verify the webpage remains responsive without a bridge, then connect authenticated WSS and ARM. Check all semantic OSC addresses in Max. Disconnect cable/network: /pm/perf/gate must return to 0; physical audio mute remains available.
9. **T09 / Performance stress**. 5 minutes single hand, 5 minutes dual hand, 5 minutes high-speed A/B/C entry/exit. Log headset display refresh, JS frame interval p50/p95/max, tracking-validity gaps, JS layer computation max and audible glitches. Proposed targets: no visible hitch >100ms, no sustained stuck gate, zero duplicate semantic events while a gesture is held. Targets must be refined from device evidence.
10. **T10 / Safe stage use**. 20 start/stop cycles, operator reset to neutral, accidental browser background/sleep, repeated WSS reconnect, Quest low battery and thermal state. Measure per-visitor reset time; goal <10s (not yet observed).
11. **T11 / Vision Pro Safari VR**. Separate compatibility exercise only. Hand support, access permission, legibility and Web Audio context unmute are device dependent. Do not claim true WebXR passthrough AR from this V2.
12. **T12 / Reproducible data**. Download JSON gesture diagnostics and existing sensor capture; label desktop traces as simulated. Keep raw joint data local unless a performer explicitly chooses to export it.

## Quantization definition

- Source events: region ENTER and EXIT from the zone engine (current 34ms dwell, 9mm enter, 14mm exit margins).
- Free mode: short impulse is scheduled at audio clock now + ~8 ms.
- Quantized mode: the impulse is scheduled on the **next sixteenth-note** boundary from the local Web Audio origin at the chosen BPM (default 100). This is not Ableton Link sync or external clock locking; do not assert tight A/V or DAW phase sync until measured.
- The local resonant phrase is finite and unquantized; one pinch excites it once. Holding does not retrigger. Zone contacts may still use the existing subdivision quantization.

## OSC channel contract V2 (additive)

Inherited sensor OSC:
- /pm/hand/{left|right}/tracked
- /pm/hand/{left|right}/index-tip
- /pm/zone/{A|B|C}/{enter|exit|tracking_lost}

Added V2 parameters, each normalized 0..1 unless noted:
- /pm/perf/gate
- /pm/perf/cutoff
- /pm/perf/resonance
- /pm/perf/wet
- /pm/perf/spread
- /pm/perf/energy
- /pm/perf/drive
- /pm/perf/hold
- /pm/perf/timbre (integer 0..2)
- /pm/perf/bpm (40..220)
- /pm/perf/quantized (integer 0/1)
- /pm/perf/zone/{A|B|C}/{zone_enter|zone_exit}
- /pm/perf/event event_name value

On stale, disconnect, or panic, bridge sends /pm/perf/gate 0, /pm/perf/hold 0 and the existing system stale flag. A physical independent mute remains mandatory for live stage work. Do not expose the bridge publicly, use a strong temporary token and trusted WSS only.

## Stress measurement caveat

V2 diagnostic JSON records JS frame-gap-derived FPS estimate and mapping-layer compute time. **This is NOT equivalent to compositor FPS, end-to-end audio latency, motion-to-photon latency, or physical OSC roundtrip.** Those require headset profiler, audio loopback, timestamped osc receiver and/or hardware.
